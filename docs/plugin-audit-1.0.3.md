- 本机电脑操控插件仍来自原始注册表包，图标补丁被覆盖；现使用套件已有的修复归档。

## 本机与通用安装包的有意差异

本机有 15 个插件，公开包有 14 个。本机的本地模型控制器保留已有供应商标识、模型名称和日志位置；语音路由保留已有密钥目录；语音通知保留用户自己的发声脚本；桌宠保留既有本机组件位置。公开包使用隔离、可移动的目录和通用配置。这些差异已逐文件审查，分别固定为归档；没有为了字节一致而搬动密钥、改写模型配置或公开私人路径。

本机额外的说人话修复包仅在本机保存。公共归档没有包含其本机专用包、用户会话、日志、凭据或本机配置。

## 实测与边界

- 本机 15 个插件的 970 个归档文件、版本、声明和锁定来源匹配；恢复两个图标补丁之外，原有运行文件未改。原链接目录中的开发测试文件仍保留在原来源目录。
- 本机空目录重装，再安装并卸载 `dsh-prompt-history@1.11.2`，原有 15 个插件的所有归档文件均未变化。该操作只发生在测试目录，没有将这个插件装回用户环境。
- 公开包 14,156 个文件通过哈希和敏感信息扫描；14 个插件的归档与安装内容逐文件相同。
- 本机与套件各通过 104 项检查：五个设置图标、纯文字标签、通知去重、Ghost 无发光、配置目录规则、全部内置来源与锁定来源、Doublecheck 守卫和报告的 Python 命令及测试文件识别。
- 公开包通过新增/卸载测试包、空目录冻结重装、移动目录后再次增删、旧来源和篡改拒绝、自定义工程规则保留。
- 本机真实 Host 中 15 个插件已启用且没有加载失败；五个设置栏目在浏览器中各一个可见 SVG。测试没有启动新的 Host 或桌宠进程。

本轮没有重新进行所有插件的端到端业务测试：真实录音、付费语音服务、模型推理、账号登录和第二台实体电脑仍不在本轮证据范围。普通账号密码登录的后续修复与实测结果见 [1.0.5 验证记录](chat-text-avatar-0.2.26.md)。此前的临时目录用户继承权限和本机工程规则仍在；不能将模型遵守规则的偏好配置视为每次都必然执行的保证。
