# 便携修复

所有改动仅限所需适配，来源版本保存在 manifest 中，最终文件以 payload-files 的 SHA-256 为准。

- 语音提醒：去掉指向原电脑个人脚本目录的依赖，随插件提供 Windows System.Speech 提醒脚本。通知仍只触发于用户发起的主会话成功完成，取消、子任务和重复结束事件不重复播报。
- 本地模型控制器：通过启动器或 Electron 的实际 resources 路径定位官方运行库，不依赖原电脑盘符。保留原本地模型启停逻辑，不复制模型路径或密钥。
- 首次注册本地模型：使用通用 `dsh-local` 标识；点击“添加到模型列表”时允许创建缺失的供应商，模型显示名来自实际文件名。不会写入原作者的供应商标识或固定模型名称，也不在日志中打印鉴权头。
- 语音配置：Gemini 和语音路由分别写入当前 `DSH_HOME`；使用独立 home 时不自动导入全局旧密钥。明确设置的进程环境变量仍遵守上游规则。
- 设置导航：语音、电脑操控、本地模型使用官方 `settings.section.icon` 注册麦克风、显示器和芯片。标签只保留文字，不再靠旧界面 CSS 隐藏齿轮。
- 桌面宠物：组件、配置、位置和 Electron 用户目录都归属于新的 DSH home；不会复用其他安装的全局桌宠状态。
- Ghost：保留 `text-shadow:none` 的无发光补丁。
- 打包：固定生产依赖，去掉 npm/pnpm 本机状态、junction、源码映射和测试夹具。所有运行文件都是真实文件；不复制任何应用核心、用户会话、凭据、日志、运行缓存或模型权重。
- 默认配置：中文、Doublecheck 提醒级别、关闭自动对抗审查。模型、语音密钥和本地路径由使用者自行填写。

- Google 登录：使用可随 home 移动的 file:./pinned-packages/ 安装来源，保留修复包、哈希及源码提交。独立附带 zod 4.6.6，其他插件继续使用原来的 zod 4.6.7。官方 DSH 0.2.2-rc.1 的插件管理器不提供该来源的常规更新。

本套件不是插件自动升级器。Google 登录插件需先核对上游正式发布包含修复，再手动移除本地来源并安装指定官方版；本套件不自动监视或切换版本。其余插件管理器更新对应包会覆盖本地补丁；升级后请重新进行图标、加载和恢复测试。旧版官方程序的支持范围不会由此自动扩大。
