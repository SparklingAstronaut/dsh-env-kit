# 文字头像账号登录修复（套件 1.0.5）

2026-11-11：在真实 DSH 桌面应用中复现普通账号密码登录后出现“CHAT 界面识别失败”、聊天区域空白。原先仅依据作者其他账号的成功测试，不能证明该账号已修好；本记录补充实际复现与修复结果。

## 原因与修改

出错账号的官网页已登录，输入框与历史列表都存在，但账号入口使用单字符文字头像，没有 img 元素。旧逻辑要求图片头像，而且把头像字符计入昵称候选，导致账号区识别失败；插件随后隐藏网页。这是页面结构兼容问题。目前证据不足以断言国际账号都存在此问题，也无需修改账号地区。

修复保留原图片头像路径，增加有边界约束的文字头像识别：单字母/数字、方形大小和页脚位置、头像与昵称相邻、单菜单图标，并排除链接、编辑框、菜单、额外文字等。设置与退出菜单沿用已确认的账号入口，识别凭据在结构变化时失效。未改登录认证、账号权限或 DSH 主程序。
