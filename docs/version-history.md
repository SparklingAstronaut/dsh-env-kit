# 版本记录

当前使用版本为 **1.0.5**。此前反馈的文字头像账号密码登录问题已在本版修复并完成实测；下面列的是版本演进，不是当前待解决清单。

| 版本 | 主要变化 |
| --- | --- |
| 1.0.5 | CHAT 0.2.26 支持文字头像，密码登录、切换、刷新、重启实测通过；其他插件修复与固定安装来源保留。 |
| 1.0.4 | 同步当时作者发布的 CHAT 0.2.23；后续文字头像适配已由 1.0.5 补齐。 |
| 1.0.3 | 补齐虚拟宠物设置图标，统一 1.1.7 版本；完善 Python 测试识别与默认工程规则。 |
| 1.0.2 | 语音升级 0.3.7，修复重复设置图标；保留猜字无发光，固定全部插件来源并验证重装与迁移。 |
| 1.0.1 | 加入 CHAT/HARNESS 网页聊天和 Google 登录适配。 |
| 1.0.0 | 首次发布隔离安装、备份恢复与桌宠组件支持。 |

历史版本仅用于追溯或回退。新安装请使用 [1.0.5 下载页](https://github.com/SparklingAstronaut/dsh-env-kit/releases/tag/v1.0.5)。
