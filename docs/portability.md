# 便携修复

所有改动仅限所需适配，来源版本保存在 manifest 中，最终文件以 payload-files 的 SHA-256 为准。

- 语音提醒：去掉指向原电脑个人脚本目录的依赖，随插件提供 Windows System.Speech 提醒脚本。通知仍只触发于用户发起的主会话成功完成，取消、子任务和重复结束事件不重复播报。
- 本地模型控制器：通过启动器或 Electron 的实际 resources 路径定位官方运行库，不依赖原电脑盘符。保留原本地模型启停逻辑，不复制模型路径或密钥。
- 首次注册本地模型：使用通用 `dsh-local` 标识；点击“添加到模型列表”时允许创建缺失的供应商，模型显示名来自实际文件名。不会写入原作者的供应商标识或固定模型名称，也不在日志中打印鉴权头。
- 语音配置：启动器将 `DSH_GEMINI_VOICE_HOME` 设置为当前 `DSH_HOME/gemini-voice`，Gemini 和语音路由分别写入当前 home；使用独立 home 时不自动导入全局旧密钥。明确设置的进程环境变量仍遵守上游规则。
- 设置导航：语音、语音路由、电脑操控、本地模型、虚拟宠物使用官方 `settings.section.icon` 注册麦克风、显示器和芯片。标签只保留文字，不再靠旧界面 CSS 隐藏齿轮。
- 桌面宠物：组件、配置、位置和 Electron 用户目录都归属于新的 DSH home；不会复用其他安装的全局桌宠状态。
- Ghost：保留 `text-shadow:none` 的无发光补丁。
- 打包：全部 14 个插件保留相对路径 tarball、SHA-256 与 pnpm 锁定文件，固定生产依赖，去掉 npm/pnpm 本机状态、junction、源码映射和测试夹具。所有运行文件都是真实文件；不复制任何应用核心、用户会话、凭据、日志、运行缓存或模型权重。
- 默认配置：中文、Doublecheck 提醒级别、关闭自动对抗审查。模型、语音密钥和本地路径由使用者自行填写。

- Google 登录：使用可随 home 移动的 file:./pinned-packages/ 安装来源，保留修复包、哈希及源码提交。独立附带 zod 4.6.6，其他插件继续使用原来的 zod 4.6.7。官方 DSH 0.2.2-rc.1 的插件管理器不提供该来源的常规更新。

本套件不是插件自动升级器。所有内置插件均来自 `file:./pinned-packages/`，其版本和实际文件一同固定。新增、卸载其他插件可以正常进行；包管理器重建依赖时从这些包恢复内置插件。不能把手工覆盖 `node_modules` 当成持久修复。

Google 登录插件需先核对上游正式发布包含修复，再主动迁移到指定官方来源；其他内置插件升级也须使用验证过的新套件或明确迁移来源。启动检查允许额外插件及依赖目录重排，但仍逐项核对内置包、安装来源和插件自身文件；首次解压则校验整个发布负载。旧版官方程序的支持范围不会由此自动扩大。

恢复已被 pnpm 管理过的 home 时，移除 node_modules 下的 `.modules.yaml` 和 `.pnpm-workspace-state-v1.json`，避免沿用旧机器或旧目录的绝对存储路径。顶层 lockfile、安装声明、归档和全部实际插件文件保留。

1.0.3 补齐 Doublecheck 守卫及报告中的 Python unittest/pytest 与测试文件识别默认配置，同时携带现有工程规则 AGENTS.md。设置和工程规则在首次安装后归用户所有，同版本恢复保留自定义内容。完整核对见 [插件审计](plugin-audit-1.0.3.md)。
